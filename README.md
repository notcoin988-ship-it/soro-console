# Soro Business Console

Интерфейс платформы Soro AI Banking Intelligence: клиентский AI, аналитика
обращений, отчёты руководству и презентационный режим «Демо».

Здесь лежит **только фронтенд**. Бэкенд, модель и база знаний работают на
машине команды и наружу не выкладываются.

## Как открыть

Есть два адреса, и выбор между ними зависит от туннеля.

### 1. Консоль с бэкенда — рабочий вариант для показа

```
https://<адрес-туннеля>/console/
```

Бэкенд отдаёт консоль сам, поэтому фронт и API живут на одном адресе:
ничего настраивать не нужно, поток ответа работает.

**Так и надо показывать заказчику.** На бесплатном ngrok при первом
открытии появится страница-предупреждение — нажать «Visit Site» один раз
до начала встречи.

### 2. Эта страница на GitHub Pages

```
https://<аккаунт>.github.io/soro-console/?api=https://<адрес-туннеля>
```

Адрес бэкенда передаётся параметром и запоминается браузером. Сбросить —
открыть с пустым `?api=`.

**Ограничение.** С бесплатным ngrok этот путь НЕ РАБОТАЕТ: туннель
отдаёт браузеру страницу-предупреждение, на ней нет CORS-заголовков, и
все запросы к API падают. Поток ответа не может даже отправить заголовок
для её обхода, а cookie согласия браузер к чужому домену не шлёт.
Вариант оживает на постоянном адресе — платный ngrok, свой домен или
бэкенд на сервере.

## Перед показом

1. На машине с бэкендом поднят туннель, адрес известен.
2. Консоль пересобрана и лежит в `dist` рядом с бэкендом — он отдаёт её
   по `/console/`.
3. Открыть `https://<туннель>/console/`, пройти предупреждение ngrok и
   проверить, что на экране «Обзор» появились цифры.
4. Для варианта с GitHub Pages дополнительно нужен `CORS_ORIGINS` в
   `.env` бэкенда с адресом страницы.

## Разработка

```
npm install
npm run dev      # http://localhost:5173, ходит в localhost:8000 через прокси
npm run build    # сборка в dist/
```

Публикация: `npm run deploy` — сборка и обновление ветки `gh-pages`
(порядок и причина — в DEPLOY.md).

## Что внутри

| Экран | Назначение |
|---|---|
| 01 Обзор | Состояние стенда, готовность к пилоту, контур безопасности |
| 02 База знаний | Загруженные документы и страницы сайта, поиск, статусы |
| 03 Площадка | Живой чат с моделью и разбор поиска — «стеклянный ящик» |
| 04 Омниканальность | Один разговор в Telegram, вебе и у оператора |
| 05 Каналы | Подключение Telegram-бота и веб-виджета |
| 06 Инбокс оператора | Очередь эскалаций, переписка, разбор диалога |
| 07 Аналитика | Живые цифры стенда и сравнение периодов |
| 08 Руководству | Показатели, находки, разбор причин, «Спросите Soro» |
| 09 Отчёты AI | Готовые отчёты: сводка, причины, рекомендации |
| 10 Безопасность | Маскирование персональных данных, изоляция, аудит |
| 11 Демо | Полный цикл продукта за две минуты, одной кнопкой |

Часть цифр на экранах 08–09 и в «Демо» — смоделированный поток обращений,
он помечен плашкой «Демо-среда». Живые данные стенда — на экранах «Обзор»,
«База знаний», «Площадка», «Инбокс» и «Аналитика».
